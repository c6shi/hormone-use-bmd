# {{ site.tagline }}

Last Updated: August 2026

This is a project that EH and I worked on for PBHLTH 243A: Targeted Learning
during the Fall 2025 semester at UC Berkeley. After presenting it to our class, 
we received suggestions and have implemented them here. This website is a 
collection of documentation on our thought process and justification for the
usage of certain methods. We would like to thank KL and MvdL for their guidance
and expertise.

Of course, since we learned about TMLE in the course, the goal of this project is to 
demonstrate the usage of TMLE and follow the causal roadmap in a real-world setting.

See github repo: https://github.com/c6shi/hormone-use-bmd.
